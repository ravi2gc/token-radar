A token launch radar: it reads a sealed DefiLlama snapshot, fits what a token is worth from the protocols whose token already trades, and ranks the protocols that record no token by expected launch value, with a farm plan for each.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
